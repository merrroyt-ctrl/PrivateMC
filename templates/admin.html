              Welt
              
  
              Neue Welt erstellen
              
    
              Die aktuelle Welt wird gelöscht und der Server erzeugt eine komplett neue. Vorher wird automatisch ein Backup gemacht, mit dem du die alte Welt wiederherstellen kannst.
              
    
    
              

              


              
  
              Backups
              
  
              Ein Backup ist eine Sicherungskopie deiner Welt. Mit „Wiederherstellen“ kommst du zu diesem Stand zurück (der aktuelle Stand wird vorher automatisch gesichert).
